# Hackathon Submission Instructions

This repository follows the **Bob AI Hackathon Submission Template** guidelines.

## Submission Checklist

- [x] `submission.yaml` - All required fields filled completely.
- [x] `README.md` - Front page project overview with architecture, tech stack, and setup instructions.
- [x] `docs/problem-statement.md` - Detailed problem analysis and target audience.
- [x] `docs/solution-overview.md` - In-depth breakdown of AI failure prediction, telemetry, and GIS mapping.
- [x] `docs/architecture.md` - Technical architecture, Mermaid diagrams, and data flows.
- [x] `docs/setup-guide.md` - Step-by-step local setup & execution guide for evaluators.
- [x] `src/` - Complete source code (frontend, backend, scripts, ML models, `.env.example`).
- [x] `demo/` - Demo video link (`demo-video-link.txt`), deployment status (`live-demo-url.txt`), and screenshot placeholders.
- [x] `presentation/` - Slide deck location (`slides.pdf` or `slides.pptx`).

Do not modify or delete `.github/workflows/validate.yml` or core top-level directory structures.
